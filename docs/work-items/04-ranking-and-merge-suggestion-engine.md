# 04 Ranking And Merge Suggestion Engine

Status: ready

## Goal

Turn repo and PR state into a ranked action list.

## Deliverables

- define readiness categories
- rank merge-ready PRs ahead of stale or blocked work
- identify likely safe worktree cleanup candidates
- emit concise reasons for each recommendation

## Notes

- keep heuristics explainable
- do not auto-merge; recommend only
